# Projeto Imobiliária R.M

Este projeto calcula o valor do aluguel de imóveis com base nas regras da empresa R.M.

## Funcionalidades
- Escolha de tipo de imóvel
- Cálculo de aluguel com garagem, quartos e desconto
- Parcelamento do contrato
- Geração de arquivo `.csv` com 12 parcelas

## Como executar
1. Abra o terminal
2. Digite: `python main.py`
3. Veja o resultado e o arquivo gerado
